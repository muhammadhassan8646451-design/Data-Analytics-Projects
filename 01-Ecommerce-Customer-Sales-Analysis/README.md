# E-Commerce Customer & Sales Analysis

A data science project analysing UK online retail transaction data using Python.

## Project Objectives

- Clean and prepare raw e-commerce transaction data
- Analyse sales and customer behaviour
- Identify top products, countries and customers
- Analyse monthly sales trends
- Perform RFM customer analysis
- Segment customers using K-Means clustering
- Generate actionable business recommendations

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

UCI Online Retail Dataset

The dataset contains more than 500,000 retail transactions including products, quantities, prices, customers, dates and countries.
