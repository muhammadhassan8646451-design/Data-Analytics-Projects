# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful and inclusive environment for everyone who participates in this project.

Contributors are expected to communicate professionally and constructively.

## Expected Behaviour

Examples of positive behaviour include:

- Being respectful to other contributors
- Giving constructive feedback
- Accepting different viewpoints and experiences
- Focusing discussions on improving the project
- Helping new contributors where possible
- Respecting privacy and personal information

## Unacceptable Behaviour

Examples of unacceptable behaviour include:

- Harassment or discrimination
- Personal attacks or insulting comments
- Threatening or abusive language
- Publishing another person's private information without permission
- Deliberately disrupting discussions or contributions
- Any behaviour that creates an unsafe or hostile environment

## Reporting Problems

If you experience or observe unacceptable behaviour related to this project, please report it to the repository owner through an appropriate private contact method.

Reports will be reviewed respectfully and confidentially where possible.

## Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Code reviews
- Other project-related communication

## Enforcement

Contributors who repeatedly violate these guidelines may have their contributions rejected or their participation restricted.

## Goal

The goal of this project is to encourage learning, collaboration and useful open-source contributions in data analytics and data science.
